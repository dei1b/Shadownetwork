# Security policy

Include the affected app version, build, or commit in your report. If practical,
check whether the issue affects the latest published release.

## Reporting a vulnerability

Use [GitHub Security Advisories](https://github.com/dei1b/Shadownetwork/security/advisories)
and select **Report a vulnerability** if available. If the button is missing,
open a GitHub issue asking for a private security contact. Keep the issue limited
to that request.

In the private report, describe the affected component, the impact, and the
conditions where the issue occurs. Use synthetic or redacted examples. Exclude
real SOS messages, personal information, credentials, and private keys.
